# Orkida Flowers — Demo Store 🌸

ديمو متجر إلكتروني + لوحة تحكم لمحل **Orkida Flowers**.

- **المتجر:** `index.html` — عرض المنتجات بالأقسام، بحث وفرز، سلة، تخصيص الهدايا، كود خصم، أجور توصيل حسب المنطقة، دفع عند الاستلام أو إلكتروني، تقييمات.
- **لوحة التحكم:** `admin.html` — (admin / orkida2026)
  - إحصائيات يومية / أسبوعية / شهرية ورسم بياني للمبيعات
  - إدارة الطلبات وتغيير حالتها
  - تعديل الأسعار بضغطة زر، إضافة/حذف منتجات، إخفاء غير المتوفر
  - العروض وأكواد الخصم، موافقة التقييمات
  - التقارير: الأكثر والأقل مبيعاً، حسب القسم، طرق الدفع، تصدير CSV
  - أجور التوصيل ومعلومات المتجر

> نسخة تجريبية: البيانات محفوظة بمتصفح الزائر (localStorage). أي تعديل بلوحة التحكم بيظهر بالمتجر فوراً على نفس الجهاز.
